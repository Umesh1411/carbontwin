# UI/UX Design Guide

## Visual direction

Premium smart-campus control room:
- Deep navy backgrounds or a restrained light theme with navy navigation.
- Cyan accent for active controls and data flow.
- Green for healthy status, amber for warnings, red for critical anomalies.
- Neutral surfaces and readable text.
- Use color with text/icons, not color alone.
- Avoid excessive glow, gradients and motion.

## Overview
- KPI cards: energy today, estimated CO2e, estimated cost, active alerts.
- Interactive campus preview.
- Energy/carbon time-series.
- Building efficiency ranking.
- Data-source/freshness indicator.
- Simulation play/pause status.

## 3D campus
- Large central viewport.
- Building search and filters.
- Toggle status coloring: energy, carbon, occupancy, alerts.
- Building details panel with current state, history and room list.
- Camera reset and view presets.
- Legend and clear simulated-data label.

## Simulator
- Play, pause, reset, speed.
- Simulation clock.
- Scenario presets.
- Event injection.
- Per-building occupancy/weather overrides.
- Event timeline.

## What-if lab
- Baseline and scenario comparison.
- HVAC/lighting/schedule/solar controls.
- Metrics for energy, CO2e, cost and comfort.
- Explain recommendation and list assumptions.
- Apply-to-virtual-twin action with confirmation.

## Accessibility and usability
- Keyboard-operable controls.
- Tooltips for technical metrics.
- Units visible everywhere.
- Responsive layout.
- Empty/loading/error states.
- Do not hide core actions in ambiguous icons.
- Respect reduced-motion preferences where practical.
